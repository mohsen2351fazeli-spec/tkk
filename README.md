# سه پادشاهی

سایت ایستای فارسی (راست‌به‌چپ) درباره سه پادشاهی، بدون فریم‌ورک؛ مناسب GitHub Pages.

## ساختار

- `index.html`، `temp/*.html`، `article/*.html`: صفحه‌ها
- `style/`، `script/`: سورس خوانا (`x.css`، `x.js`) و کنارش نسخه فشرده (`x.min.css`، `x.min.js`). صفحه‌ها نسخه `.min` را بارگذاری می‌کنند
- `pic/`، `pict/`، `pngpic/`، `poster/`: تصاویر. صفحه‌ها نسخه `.webp` را نشان می‌دهند؛ فایل PNG/JPG/GIF اصلی کنارش نگه داشته شده
- `music/`: آهنگ‌ها
- `sw.js`: سرویس‌ورکر کش (توضیح پایین)

## بعد از ویرایش CSS یا JS

```
node tools/minify.mjs
```

نسخه‌های `.min` دوباره ساخته می‌شوند (به Node نیاز دارد؛ esbuild را خودش با `npx` می‌گیرد). اگر فقط `x.css` را ویرایش کنید و این دستور را نزنید، سایت همان نسخه قبلی `x.min.css` را نشان می‌دهد.

## تصویر جدید

تصویر را به WebP تبدیل کنید (کیفیت حدود ۸۰) و در `src` همان `.webp` را بنویسید.

## کش

GitHub Pages اجازه تنظیم هدر `Cache-Control` را نمی‌دهد (ثابت و حدود ۱۰ دقیقه است). برای همین `sw.js` در مرورگر بازدیدکننده:

- تصویر و فونت را نگه می‌دارد و بار بعد بدون درخواست به سرور نشان می‌دهد (هفته‌ای یک بار در پس‌زمینه دوباره بررسی می‌کند)
- صفحه، CSS و JS را اول از شبکه می‌گیرد تا تغییرهای تازه فوری دیده شوند، و فقط وقتی شبکه نیست از نسخه ذخیره‌شده استفاده می‌کند
- موزیک‌ها را دست نمی‌زند

اگر تصویری را با همان نام عوض کردید و می‌خواهید همه بازدیدکننده‌ها فوراً نسخه جدید را بگیرند، در `sw.js` مقدار `VERSION` را عوض کنید.
